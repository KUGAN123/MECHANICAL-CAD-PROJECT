# Mechanical Part Design Using SolidWorks

## Project Overview
This project focuses on designing and modeling mechanical components using **SolidWorks 3D CAD software**. It demonstrates fundamental mechanical design concepts, 3D part modeling, feature creation, and engineering design practices.

## Objectives
- Develop 3D mechanical parts using SolidWorks.
- Understand basic sketching and modeling tools.
- Apply dimensions and geometric constraints.
- Create accurate mechanical component designs.
- Improve practical CAD modeling skills.

## Software Used
- **Software:** SolidWorks
- **Technology:** 3D CAD Modeling
- **File Formats:** `.SLDPRT`, `.SLDASM`, `.SLDDRW`, `.STEP`

## Design Features
- 2D sketch creation
- Extrude and Cut-Extrude operations
- Revolve and Fillet features
- Chamfer and Hole operations
- Dimensioning and geometric constraints
- 3D model visualization

## Project Workflow
1. Open SolidWorks and create a new part.
2. Select a reference plane.
3. Create a 2D sketch using drawing tools.
4. Apply dimensions and constraints.
5. Convert the sketch into a 3D model using features.
6. Add fillets, chamfers, and other finishing operations.
7. Save and export the completed mechanical part.

## Project Files
- `Part1.SLDPRT` – SolidWorks 3D part model
- `Part1.STEP` – Exported 3D model (if available)
- `Images/` – Screenshots of the mechanical design
